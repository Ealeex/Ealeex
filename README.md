I've been programming since I was young, and I enjoy experimenting with new technologies, exploring unfamiliar concepts, and building projects that challenge my understanding of software.

- **Languages:** C, C++, JavaScript, TypeScript, Python
- **Web:** Node.js, Next.js, React, HTML, CSS
- **Systems:** Linux, Windows, networking, sockets, and asynchronous I/O
- **Tools:** Git, GCC, CMake, Visual Studio Code, PowerShell, Bash

### What interests me

- **Systems programming:** Exploring memory management, operating systems, and low-level APIs.
- **Networking:** Building clients, servers, and experimenting with network protocols.
- **Web development:** Creating interactive applications and experimenting with modern frameworks.
- **Space & simulation:** Interested in aerospace, orbital mechanics, and realistic simulations.
- **Learning:** Understanding the *why* behind the technologies I use, not just how to use them.
